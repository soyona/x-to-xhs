# Progress

## 已完成

### 项目规则与知识库

- `.codexrules` 是唯一的新会话规则入口。
- `memory-bank/` 按项目、产品、技术、系统、当前状态和进度分层。
- 已移除内容重复的 `AGENTS.md`。

### 项目基础

- React + Vite 本地单页应用。
- Node 原生 HTTP 服务。
- 开发模式同时启动前后端。
- 开发模式自动监听并重启后端，避免前端热更新后仍连接旧版历史接口。
- 生产静态文件与 API 由同一 Node 服务提供。

### 输入与提示词

- 支持完整 X 文本。
- 支持单条 X/Twitter 帖子 URL。
- 使用 X oEmbed 解析公开正文。
- 拒绝无法可靠解析、只返回短链的内容。
- 每次从 `Long-form-post-prompt.md` 读取最新规范。
- 正文由提示词直接生成保留`#`、`##`、`-`和`1.`的结构化粘贴文本。
- 正文按原文信息量自然展开，不设最低字数，只执行 10000 字上限。
- 章节数量和节点数量服从实际内容，不通过固定篇幅要求制造冗余。
- 支持目标读者、目标、语气、深度、术语、案例、Emoji 和行动建议等
  结构化创作偏好。
- 支持作者身份、禁用表达和 500 字以内补充指令。
- 偏好经服务端白名单清洗后注入生成与修复 Prompt，不能覆盖固定协议。

### 模型调用

- Gemini 默认。
- Groq Qwen 备用。
- 智谱 `glm-4.7-flash` 国内免费备用。
- 硅基流动 `Qwen/Qwen3.5-4B` 国内免费备用。
- OpenRouter Free 兜底。
- 自动跳过未配置服务。
- 处理 Key 权限、配额、限流、超时和服务端错误。
- 支持 HTTP/HTTPS/ALL_PROXY。

### 生成与发布

- 正文使用 Markdown H1、H2、无序列表和有序列表标记；固定尾部分区
  继续用于拆分。
- 正文结构化排版由提示词控制，兼容清理层保留目标标记和连续空行。
- `02` 展示唯一的结构化正文源稿；剪贴板富文本和纯文本兜底均由它
  确定性派生。
- 正文复制同时提供`text/html`标题/列表语义和无井号`text/plain`兜底。
- 分页由小红书“一键排版”处理；提示词禁止伪分页信号，兼容清理会移除
  旧稿中的 `---` 和文字版页脚。
- 兼容清理模型偶尔残留的 Markdown 装饰语法。
- 拆分长文标题、正文、发布标题、正文描述、标签。
- 正文描述固定使用“2句短导语、3行连续编号要点、1段收束语”的3块
  纯文本排版，拆分与复制保留空行和编号。
- 缺少摘要时从正文结尾提取描述。
- 缺少标签时提供通用标签兜底。
- 按 7 步流程分别复制。
- 第 02 步可将同一正文数据源导出为 UTF-8 Markdown 文件，用于小红书
  “从文件导入”；文件不包含标题、摘要、标签和审稿自查。
- 01、02、04、05、06 使用统一的内容顶部操作栏；重新生成与复制、导出
  使用同规格图标按钮并排展示，正文预览占满可用宽度且支持展开/收起。
- 移动端重新生成、复制与导出按钮保持至少 44px 高度，导出反馈不隐藏。
- 所有图标操作仍保留具名无障碍文本和悬停提示。
- 第 01 步和第 04 步首次及再次生成均分别提供 3 个标题候选；发布标题
  成为独立字段并限制不超过 20 字。
- 第 02、05、06 步支持主动重新生成；候选确认前不覆盖当前内容。
- 采用新正文后，第 04、05、06 步显示“基于上一版正文”，各自重新生成
  或选择新候选后独立清除。
- 新增`POST /api/generate-section`，对局部候选执行确定性校验；标签当前
  明确返回`content-only`，不伪装实时趋势数据。

### 规范检查

- 11 项自动检查。
- 摘要检查同时验证220–280字、3个内容块和`1.`至`3.`连续编号。
- 8 项人工复核。
- 取消独立检查栏，按发布步骤内联展示。
- 整稿顶部显示通过数与失败数。
- 未通过项就地显示当前值、目标要求和“修复此部分”。
- 通过项默认折叠；人工复核支持逐项勾选。
- 自动失败计数不包含人工项。
- 固定格式禁止额外尾部分区。

### 自动处理

- 局部修复。
- 结构化修订。
- 整篇重生。
- 重新验证。
- 最多两次自动处理。
- 第二次可切换模型。
- 恢复上一版本。

### API 配置

- 页面右上角配置入口。
- 密码输入、不回显已保存 Key。
- 保留、替换、清除 Key。
- 修改模型。
- 新增或保留 API Key 时同步显式保存对应模型，包括与内置默认值相同的模型。
- `.env` 安全合并和原子写入。
- 占位符检测。

### 创作偏好

- 右上角“设置”是唯一入口，输入区不重复显示偏好或入口。
- 设置弹窗分为“创作偏好”和“模型与 API”。
- 偏好保存在浏览器本地，不与 API Key 混存。
- 支持一键恢复默认偏好。

### 历史笔记

- 右上角“查看历史”入口。
- 首次生成自动创建记录，修复结果追加为同一记录的新版本。
- 本地 JSON 原子写入、有效文件备份和损坏回退。
- 最近更新时间倒序、50 条顶层记录限制、每条最近 3 个版本。
- 支持历史列表、版本查看、载入工作区和二次确认删除。
- 载入历史恢复原始内容、草稿、模型与创作偏好，不调用模型。
