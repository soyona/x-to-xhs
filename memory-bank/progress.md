# Progress

## 已完成

### 项目规则与知识库

- `.codexrules` 是唯一的新会话规则入口。
- `memory-bank/` 按项目、产品、技术、系统、当前状态和进度分层。
- 已移除内容重复的 `AGENTS.md`。

### 项目基础

- React + Vite 本地单页应用。
- Node 原生 HTTP 服务。
- 开发模式同时启动前后端。
- 生产静态文件与 API 由同一 Node 服务提供。

### 输入与提示词

- 支持完整 X 文本。
- 支持单条 X/Twitter 帖子 URL。
- 使用 X oEmbed 解析公开正文。
- 拒绝无法可靠解析、只返回短链的内容。
- 每次从 `Long-form-post-prompt.md` 读取最新规范。

### 模型调用

- Gemini 默认。
- Groq Qwen 备用。
- OpenRouter Free 兜底。
- 自动跳过未配置服务。
- 处理 Key 权限、配额、限流、超时和服务端错误。
- 支持 HTTP/HTTPS/ALL_PROXY。

### 生成与发布

- 生成内部 Markdown 草稿。
- 清理 Markdown 为小红书可粘贴文本。
- 拆分长文标题、正文、发布标题、正文描述、标签。
- 缺少摘要时从正文结尾提取描述。
- 缺少标签时提供通用标签兜底。
- 按 7 步流程分别复制。

### 规范检查

- 11 项自动检查。
- 8 项人工复核。
- 父子分组展示。
- 自动失败计数不包含人工项。
- 固定格式禁止额外尾部分区。

### 自动处理

- 局部修复。
- 结构化修订。
- 整篇重生。
- 重新验证。
- 最多两次自动处理。
- 第二次可切换模型。
- 恢复上一版本。

### API 配置

- 页面右上角配置入口。
- 密码输入、不回显已保存 Key。
- 保留、替换、清除 Key。
- 修改模型。
- `.env` 安全合并和原子写入。
- 占位符检测。

### UI

- 三栏桌面工作区。
- 移动端三段等高布局。
- 整页无纵向或横向滚动。
- 各面板内部独立滚动。
- API 设置响应式弹窗。
