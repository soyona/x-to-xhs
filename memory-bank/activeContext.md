# Active Context

更新日期：2026-08-01

## 当前状态

项目是一个本地运行的 X → 小红书长文工作流：

- 输入统一作为原始素材处理；明确的 X URL 仍可自动识别和解析，但不再要求
  用户选择素材类型。
- Gemini → Groq Qwen → 智谱 GLM → 硅基流动 Qwen →
  OpenRouter Free 自动降级。
- 每家服务支持单选或有序多选模型；多选时先在同一服务内按顺序降级，
  再进入下一家服务。
- Gemini 支持在 `GEMINI_API_KEY` 中按顺序配置逗号分隔的多个 Key；
  当前 Key 额度、限流、无效或无权限时尝试下一个，无法继续时再进入模型降级链路。
- 每次模型调用保存脱敏的尝试详情：供应商、Key 序号、结果、标准化原因、
  HTTP 状态和耗时；完整 Key、输入正文和模型完整响应不会进入详情或历史。
- `02 小红书长文`按 7 步流程拆分标题、正文、发布标题、正文描述和标签。
- 正文支持富文本复制、纯文本兜底和 Markdown 导出。
- 标题、正文、正文描述和标签支持主动重新生成；标题的 3 个候选只在内容
  预览区展示，单击不采用，双击相应候选直接复制。
- 本地历史支持查看、载入和删除。
- 自动降级路径随历史版本保存，重新载入后仍可查看。
- API Key 只保存在服务端 `.env`。

## 提示词架构

- `Long-form-post-prompt.md` 是系统默认提示词。
- 默认文件包含六个模块：`global`、`title`、`body`、`summary`、`tags`、
  `output`。
- `promptStore.mjs` 每次读取默认文件；直接修改后，下次生成立即生效。
- 页面“创作设置”只管理提示词方案，开放全局、标题、正文、正文摘要和标签
  五个模块。
- 页面自定义方案保存在 `.local-data/prompts.json`，目录权限为 `700`，
  文件权限为 `600`。
- 自定义方案可覆盖全局与四个内容模块；固定输出协议继承默认模板。
- 完整生成与局部重新生成使用同一个当前方案。
- 正文模块明确区分完整稿件与局部 `body` 生成；局部正文不输出文章标题、
  正文摘要或推荐标签。
- 页面和服务端不再维护独立表达偏好；完整生成与局部重新生成只使用当前
  提示词方案。
- 页面支持下载默认模板、下载当前方案和上传完整 Markdown 模板；上传只做
  模块完整性和固定输出协议检查，不执行内容 validation。

## 内容处理边界

- 内容规则完全由当前提示词方案负责，不在代码中重复写死。
- 提示词不再接收或推断素材类型；所有输入遵循统一的事实、改写与归属边界。
- 来源元数据由服务端结构化保存，正文署名在复制与导出阶段确定性附加，
  不依赖模型生成。
- X 原文缺少链接时允许生成草稿，但输入区和发布步骤持续提示补充来源。
- 页面不执行标题字数、Emoji、章节、摘要长度或标签数量等内容 validation。
- 模型内容不符合提示词时仍返回页面，由用户判断并主动重新生成。
- 系统只保留技术协议检查：JSON 可解析、候选非空、候选数量正确。
- 完整生成和局部生成都将素材、当前稿件、旧候选及用户反馈序列化为不可信
  JSON 数据；这些字段中的指令、模块标记和边界文本不得执行。
- 已移除 `src/validation.js`、`src/repairStrategy.js`、
  `src/RepairControls.jsx` 和 `/api/repair`。
- 新稿不再包含`【审稿自查】`；拆分层继续兼容包含该分区的旧历史稿。

## 默认提示词摘要

- 标题默认 16–20 字、恰好 1 个可见 Emoji；3 个候选的内容角度完全由标题
  模块负责，代码只固定候选数量协议。
- 正文按素材信息量自然展开，不设最低字数，不超过 10000 字。
- 素材有限时减少章节并可省略框架总览；只有导语、摘要或预告时只整理已知
  信息与尚未展开内容。
- 第三方素材中的事实性主张必须能对应输入依据；导语、摘要或内容预告不得
  被补写成定义、技术模式、案例、失效原因、性能收益或行动步骤。
- “本文分析”仅允许素材内归纳、比较、结构化解释和有限推断；外部事实、
  行业数据、案例、因果结论与实践效果仍不得补写。
- 提示词示例只用于说明语言或排版格式，不得作为正文事实；当前提示词不接收
  外部补充背景，只允许使用输入素材支持的信息。
- 摘要在信息充足时为 200–260 字；正文信息有限时允许自然缩短。
- 标签默认 8 个，素材信息有限时允许 4–8 个，不虚构场景、目标人群或效果。
- 固定输出协议使用无占位符的顺序规则，正文尾部只保留可被拆分层识别的
  `正文小结 / 摘要`和`推荐标签`两个固定标题。

## 当前 UX

- 设置弹窗包含“创作设置”和“模型与 API”；候选模型可在线增删，
  Gemini 内置 3.6 Flash、3.5 Flash 和 2.5 Pro。
- Gemini API 设置提示多个 Key 使用英文逗号分隔，已保存 Key 仍不回显。
- 生成结束后底部状态栏可展开“生成详情”；降级成功会说明最终供应商，
  全部失败会保留脱敏的逐次尝试原因。
- 设置弹窗保持稳定工作区高度；提示词内容区独立滚动，底部操作保持可见。
- 提示词方案支持选择、新建副本、编辑五个模块、保存、删除、恢复模块默认值、
  下载默认模板、下载当前方案和上传模板。
- 系统默认方案来自受版本管理的 `Long-form-post-prompt.md`；页面保存会创建本地
  自定义方案，不直接修改默认文件。
- `02` 顶部仅说明内容由当前提示词控制，不显示通过数、失败数或修复入口。
- 第 7 步为“预览并发布”；正文变化后继续提示发布标题、描述和标签可能过期。
- 输入区统一接收原始素材，并自动识别明确的 X URL。
- 第 2 步正文预览、富文本复制和 Markdown 导出使用同一落款规则。
- 第 7 步提示核验作者、原帖链接、引用、事实和 AI 内容声明，不依赖素材类型。

## 工作区提醒

- `.env` 包含本地密钥，永远不要读取后原样输出或加入 Git。
- `.local-data/` 被 Git 忽略，不得提交其中的历史稿或自定义提示词。

  `promptStore.mjs` 和相关测试。
