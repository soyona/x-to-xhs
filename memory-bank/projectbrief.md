# Project Brief

## 一句话定义

把用户粘贴的 X 帖子正文或单条帖子 URL，转换成可按步骤复制到小红书「写长文」的中文长文草稿，并在本地完成确定性规范检查。

## 核心目标

- 以 [`Long-form-post-prompt.md`](../Long-form-post-prompt.md) 为内容合同生成长文。
- 降低从 X 内容到小红书长文的改写、排版和发布成本。
- 在调用模型后立即检查标题、正文、摘要、标签和固定分区。
- 把 Markdown 内部稿拆成小红书发布流程需要的独立字段。
- 在一家免费模型不可用时自动切换到下一家。
- 所有 API Key 只保存在本机。

## 明确范围

### 包含

- X 完整文本输入。
- 单条 `x.com` / `twitter.com` 帖子 URL。
- 小红书「写长文」笔记。
- Markdown 生成稿、纯文本复制稿、规范检查、自动修复。
- 本地 API 配置。

### 不包含

- 视频笔记。
- 普通图文笔记。
- 播客。
- 自动登录或自动发布到小红书。
- 代替人工事实核查、原创性判断和内容质量审稿。

## 成功标准

- 用户可以在一个固定视口内完成输入、生成、检查和分段复制。
- 生成结果能稳定拆出标题、正文、描述和标签。
- 自动检查与 Markdown 规范保持一致。
- 模型失败时自动降级，并给出可理解的错误。
- 密钥不进入浏览器响应、源码或 Git。
