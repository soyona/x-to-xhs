# Project Brief

## 一句话定义

把用户粘贴的 X 帖子正文或单条帖子 URL，转换成可按步骤复制到小红书
「写长文」的中文草稿，并允许用户通过提示词方案控制生成规则。

## 核心目标

- 以 `Long-form-post-prompt.md` 为系统默认提示词。
- 支持在页面分别配置全局、标题、正文、正文摘要和标签提示词。
- 完整生成与局部重新生成使用同一个当前提示词方案。
- 内容不满意时由用户主动重新生成，不使用代码 validation 或自动修复。
- 把 Markdown 草稿拆成小红书发布流程需要的独立字段。
- 一家模型不可用时自动切换到下一家。
- API Key、自定义提示词和历史稿只保存在本机。

## 明确范围

### 包含

- X 完整文本和单条帖子 URL。
- 小红书「写长文」笔记。
- 模块化默认提示词和本地自定义提示词方案。
- 长文标题、正文、发布标题、正文描述和标签重新生成。
- 结构化复制、富文本与纯文本兜底、Markdown 正文导出。
- 本地 API 配置和历史笔记。

### 不包含

- 内容规则的确定性 validation 或自动修复。
- 视频、普通图文笔记、播客。
- 自动登录或自动发布到小红书。
- 代替人工事实核查、原创性判断和发布前审稿。

## 成功标准

- 修改全局或四个内容模块时无需修改代码、测试或 UI 文案。
- 直接修改默认 Markdown 后，下次生成立即生效。
- 页面方案可以创建、切换、编辑和删除。
- 模型内容不会因偏离提示词而被系统拒绝。
- 生成结果能稳定拆出标题、正文、描述和标签。
- 模型失败时自动降级，并给出可理解的错误。
- 密钥与本地内容不进入源码、Git 或日志。
