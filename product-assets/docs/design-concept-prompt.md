# Design concept prompt

Use case: `ui-mockup`

Create a complete, polished desktop web-app concept for a local X-to-Xiaohongshu converter used by Chinese AI-tool builders and content creators. It accepts pasted X text or an X URL, generates a ready-to-paste Chinese Xiaohongshu long-form Markdown draft, validates all required sections and word counts, and supports one-click copy.

Use a quiet header with the code-native wordmark “X → 小红书” and “本地运行”. Build the main workspace as three purposeful regions: a source panel titled “粘贴 X 内容” with a large textarea and coral “生成小红书长文” button; a wider generated Markdown document preview with “复制全文”; and an always-visible “规范检查” rail for title, body, summary, image suggestions, tags, structure, formatting advice, and review checks.

Visual direction: editorial writing desk meets modern developer tool. Use a true-white canvas, pale cool-gray page background, deep ink text, restrained coral accent, subtle paper texture only in the document, crisp one-pixel borders, 8–12 px radii, almost no shadows, generous whitespace, Chinese editorial serif for document headings, and clean Chinese sans-serif for app controls. Keep app text and controls code-native and make the design practical for React + Vite.

Do not create a landing page, marketing hero, fake metrics, decorative filler, default card grid, eyebrow or badge above a heading, gradient, neon, glow, unrelated navigation, analytics dashboard, oversized rounded container, stock imagery, or extra product claims.
